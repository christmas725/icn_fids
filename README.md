# ICN FIDS v0.2 — Web / PWA

인천국제공항 여객 출발편을 인천공항 FIDS 스타일로 표시하는 Next.js 프로젝트입니다.

## v0.2 현재 구성

- 인천공항 홈페이지 출발 피드(`airport.kr`)를 화면 표시 기준 데이터로 사용
- 인천국제공항공사 상세 OpenAPI로 미래편/코드쉐어 메타데이터/자정 전환 보강
- 여객편 운항현황(다국어) OpenAPI는 홈페이지 피드 장애 시 fallback
- `P01 + P02(탑승동) = T1`, `P03 = T2`
- 실제 `출발/Departed` 상태가 확인된 항공편은 목록에서 제거
- 00:00~02:00 전날 미출발·지연편 보호
- 코드쉐어는 한 실제 운항으로 묶고 편명/항공사 로고 순환
- 단독운항편은 코드쉐어 순환 중에도 정적으로 유지
- 목적지/현황: 한국어 → 영어 → 목적지 국가 언어 순환
- 각 언어 단계에서 코드쉐어 편명을 모두 보여준 뒤 다음 언어로 전환
- 페이지당 15개 실제 운항, **최대 2페이지(최대 30개 운항)**
- 전체/T1/T2 전환: 좌측 터미널 영역 클릭 또는 키보드 `1 / 2 / 3`
- 홈페이지 데이터 60초마다 클라이언트 갱신
- Web + 설치형 PWA 지원

## 로컬 실행

```powershell
npm.cmd install
npm.cmd run dev
```

`.env.local`:

```env
INCHEON_API_KEY=공공데이터포털_일반인증키
FIDS_DEMO_MODE=false
```

브라우저:

```text
http://localhost:3000
```

API 확인:

```text
http://localhost:3000/api/departures
```

정상적인 홈페이지 피드 사용 시 응답의 `source`는 `airport.kr`입니다.

## Vercel 웹 배포

1. 이 폴더를 GitHub 저장소에 업로드합니다.
2. Vercel에서 저장소를 Import합니다.
3. Project Settings → Environment Variables에 다음을 등록합니다.
   - `INCHEON_API_KEY` = 공공데이터포털 일반 인증키
   - `FIDS_DEMO_MODE` = `false`
4. Deploy 합니다.

`app/api/departures/route.ts`는 Vercel 서울 리전(`icn1`)을 선호하도록 설정되어 있습니다.

> `.env.local` 파일은 GitHub에 올리지 마세요.

## 웹앱(PWA)

Vercel처럼 HTTPS로 배포하면 브라우저에서 설치 가능한 웹앱으로 사용할 수 있습니다.

- Android/Chrome: 메뉴 → 앱 설치 / 홈 화면에 추가
- Windows/Chrome·Edge: 주소창의 설치 아이콘 또는 메뉴 → 앱 설치
- iPhone/iPad Safari: 공유 → 홈 화면에 추가

설치 시 `standalone` 모드로 실행되며 브라우저 UI가 최소화됩니다.
실시간 운항정보(`/api/departures`)는 Service Worker에 캐시하지 않으므로, 설치형 웹앱에서도 항상 서버의 최신 데이터를 요청합니다.

## 페이지 정책

화면은 코드쉐어를 하나의 실제 운항으로 계산하여 현재 선택한 `전체 / T1 / T2` 기준으로 앞에서부터 최대 30개 운항만 사용합니다.

- 1~15개: `01 / 01`
- 16~30개: `01 / 02` ↔ `02 / 02`
- 31개 이상: 앞의 30개만 표시하여 **3페이지 이상 생성하지 않습니다.**

## 데이터 주의사항

- `airport.kr` 홈페이지 피드는 문서화된 공공 OpenAPI가 아니라 인천공항 공식 홈페이지가 사용하는 웹 피드입니다. 홈페이지 구조 변경 시 파서 수정이 필요할 수 있습니다.
- 상세 OpenAPI와 여객 OpenAPI는 fallback/보강 용도로 유지합니다.
- 실제 공항 현장 FIDS와 공개 홈페이지 사이에는 반영 시점 차이가 있을 수 있습니다.
## v0.2 고정 15행 표시

- 페이지당 15편 기준은 그대로 유지합니다.
- 마지막 페이지에 실제 운항편이 15편보다 적으면 남는 칸은 빈 행으로 채웁니다.
- 따라서 1페이지와 마지막 페이지의 행 높이/격자 크기가 항상 동일합니다.
- 최대 2페이지(실제 운항 최대 30편) 제한은 그대로 유지합니다.
